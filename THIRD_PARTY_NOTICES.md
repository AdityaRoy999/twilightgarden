# Third-party artwork

Solar icons by **480 Design**, licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Original collection: https://www.figma.com/community/file/1166831539721848736

SVG data distributed by https://github.com/iconify/icon-sets (Solar collection).
Twilight uses a local subset with a compatibility-name adapter and theme-aware
duotone colors. Source SVG geometry is preserved; display colors and sizes are
adapted. No remote icon API is used at runtime.
